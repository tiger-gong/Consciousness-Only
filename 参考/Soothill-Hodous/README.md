# Soothill & Hodous, *A Dictionary of Chinese Buddhist Terms*（1937）

公版汉英佛学辞典。Charles Muller 主持数字化（2002–2005），法鼓佛教学院（今法鼓文理学院）整理为 TEI P5，并做成多种阅读格式。数字整理本另标 [CC BY-SA 3.0](http://creativecommons.org/licenses/by-sa/3.0/)。

来源：[DILA Glossaries · SHH](https://glossaries.dila.edu.tw/glossaries/SHH?locale=en)

**用法提醒**：Muller 自己也说，瑜伽行派等名相偏旧、宜当线索，不宜当本库或 DDB 的最终依据。本库名相仍以 Cook / 讲记词典为准；这里用来查 1930 年代通行的汉英对译、梵汉对照，或核对旧译。

## 本目录有什么

| 文件 | 格式 | 怎么用 |
| --- | --- | --- |
| `soothill-hodous.dila.htm` | 单个 HTML（约 16,000 条） | 用浏览器打开，`⌘F` 搜汉字、拼音或英文。Obsidian 里点文件，再用「用默认应用打开」。 |
| `soothill-hodous.dila.epub` | EPUB | Apple 图书、Calibre、电子书阅读器。适合整本翻、加书签。 |
| `ddbc.soothill-hodous.tei.p5.xml` | TEI P5 XML | 给脚本/检索用：按 `<entry>` 抽词头、释义。不要拆成数千个 md，否则会冲进图谱。 |

未下载的格式（需要时再取）：DILA 网站还有 PDF、StarDict、Babylon。StarDict 可配合 GoldenDict 做划词。

## 在 Obsidian 里怎么查

1. 文件列表打开本文件夹，点 `soothill-hodous.dila.htm` → 用浏览器打开。
2. 或把 EPUB 拖进图书。
3. **不要**把词条拆进 `名相词典/`。那是本库自己的四语词条；Soothill 只放在 `参考/`，避免图谱再多一层节点。
