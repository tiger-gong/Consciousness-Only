# condition as perceptual object
> 校准自「object-as-condition」，依 Cook, *Three Texts on Consciousness Only*。

**梵 / Sanskrit**：*ālambana-pratyaya*

## Explanation（English）
The object taken as a condition, able to draw forth the cognizing mind. Divided into intimate condition as perceptual object (the image-aspect) and remote condition as perceptual object (the essential object).
