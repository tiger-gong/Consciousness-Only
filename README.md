## 如何用 Obsidian 学习本书

先读现代语言导读，再进二十二讲：[Hundred Dharmas/Readers Guide](Hundred%20Dharmas/Readers%20Guide.md)。

讲记正文里的 `[[名相词典/中文/阿赖耶识|阿賴耶識]]` 这类链接，是按 [Obsidian](https://obsidian.md/) 的维基链接（`[[页面|显示名]]`）写的。用普通编辑器只能看到括号；把本仓库当作 Obsidian 库打开后，点词条会跳到释义，图谱视图也能画出讲记与名相之间的知识网络。我们已为四语名相当中的主要概念建了交叉链接，图谱、反向链接、本地搜索都可以直接用。

### 免费下载全书 EPUB

不装 Obsidian 也可以先读完全书：四语对照 EPUB（第 1–22 讲，虚线名相可点开释义）免费提供。

- 仓库内文件：[Hundred Dharmas/100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/blob/main/Hundred%20Dharmas/100%20Dharmas.epub)
- 直接下载：[100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/raw/main/Hundred%20Dharmas/100%20Dharmas.epub)

### 两种打开方式

1. **用 Git 插件克隆到本地**  
   安装 [Obsidian](https://obsidian.md/) 与社区插件 **Obsidian Git**。在 GitHub 账号里生成 [Personal Access Token](https://github.com/settings/tokens)（个人密钥），在插件里填入用户名和密钥。然后把本仓库网址拖入或填入克隆地址：

   `https://github.com/tiger-gong/Consciousness-Only.git`

   克隆完成后，用 Obsidian「打开文件夹作为库」。

2. **先下载完整目录，再加成本地库**  
   在 GitHub 页面点 **Code → Download ZIP**，解压后，在 Obsidian 里选「打开文件夹作为库」，指向解压出的目录即可。适合暂时不想配置 Git 的读者。

欢迎阅读、修正、补译。请在自己的分支或 fork 上修改，再开 Pull Request。

## How to study this book in Obsidian

Start with the modern-language companion, then the twenty-two lectures: [Hundred Dharmas/Readers Guide](Hundred%20Dharmas/Readers%20Guide.md).

Links in the lecture files such as `[[名相词典/English/store consciousness|store consciousness]]` follow [Obsidian](https://obsidian.md/) wiki-link syntax (`[[page|display text]]`). In a plain editor they look like brackets; once this repository is opened as an Obsidian vault, a tap jumps to the glossary note. Graph view then shows the knowledge map we built among the lectures and the four-language terms (backlinks and local search work the same way).

### Free EPUB of the complete book

You can read the whole work without Obsidian. The four-language parallel EPUB (lectures 1–22, dotted terms open as notes) is free to download.

- In the repo: [Hundred Dharmas/100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/blob/main/Hundred%20Dharmas/100%20Dharmas.epub)
- Direct download: [100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/raw/main/Hundred%20Dharmas/100%20Dharmas.epub)

### Two ways to open the vault

1. **Clone with the Git plugin**  
   Install [Obsidian](https://obsidian.md/) and the community plugin **Obsidian Git**. Create a GitHub [Personal Access Token](https://github.com/settings/tokens), enter your username and the token in the plugin, then drag or paste this URL as the clone address:

   `https://github.com/tiger-gong/Consciousness-Only.git`

   When the clone finishes, use Obsidian’s “Open folder as vault”.

2. **Download the full folder, then add it as a local vault**  
   On GitHub click **Code → Download ZIP**, unzip it, then in Obsidian choose “Open folder as vault” and point to that folder. Use this if you do not want to set up Git yet.

Please read, correct, and fill gaps. Work on your own branch or fork, then open a pull request.

## Comment étudier ce livre dans Obsidian

Les liens du type `[[名相词典/Français/conscience-réceptacle|conscience-réceptacle]]` suivent la syntaxe wiki d’[Obsidian](https://obsidian.md/) (`[[page|texte affiché]]`). Dans un éditeur ordinaire, ce ne sont que des crochets ; ouvert comme coffre Obsidian, un tap ouvre la notice. La vue graphe montre le réseau de connaissances que nous avons tissé entre les conférences et les termes en quatre langues (rétroliens et recherche locale compris).

### EPUB gratuit du livre entier

On peut lire l’ouvrage sans installer Obsidian. L’EPUB parallèle en quatre langues (conférences 1–22 ; les termes en pointillés ouvrent la glose) est en téléchargement libre.

- Dans le dépôt : [Hundred Dharmas/100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/blob/main/Hundred%20Dharmas/100%20Dharmas.epub)
- Téléchargement direct : [100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/raw/main/Hundred%20Dharmas/100%20Dharmas.epub)

### Deux façons d’ouvrir le coffre

1. **Cloner avec le greffon Git**  
   Installer [Obsidian](https://obsidian.md/) et le greffon communautaire **Obsidian Git**. Créer un [jeton d’accès personnel](https://github.com/settings/tokens) GitHub, saisir le nom d’utilisateur et le jeton dans le greffon, puis glisser ou coller l’URL de clonage :

   `https://github.com/tiger-gong/Consciousness-Only.git`

   Ensuite, « Ouvrir le dossier en tant que coffre ».

2. **Télécharger le dossier complet, puis l’ajouter en coffre local**  
   Sur GitHub : **Code → Download ZIP**, décompresser, puis dans Obsidian « Ouvrir le dossier en tant que coffre ». Utile si l’on ne veut pas encore configurer Git.

Lecture, corrections et compléments sont les bienvenus : branche ou *fork*, puis *pull request*.

## Cách học sách này trong Obsidian

Các liên kết như `[[名相词典/TiếngViệt/thức A-lại-da|thức A-lại-da]]` viết theo cú pháp wiki của [Obsidian](https://obsidian.md/) (`[[trang|chữ hiện]]`). Trong trình soạn thường chỉ thấy ngoặc vuông; mở kho này như vault Obsidian thì chạm thuật ngữ sẽ tới lời giải. Graph view hiện bản đồ tri thức chúng tôi đã dựng giữa các bài giảng và danh tướng bốn ngữ (backlink và tìm kiếm nội bộ dùng được ngay).

### Tải miễn phí EPUB toàn sách

Không cần cài Obsidian vẫn đọc hết. EPUB đối chiếu bốn ngữ (bài 1–22; thuật ngữ gạch chấm mở chú thích) được cung cấp miễn phí.

- Trong kho: [Hundred Dharmas/100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/blob/main/Hundred%20Dharmas/100%20Dharmas.epub)
- Tải trực tiếp: [100 Dharmas.epub](https://github.com/tiger-gong/Consciousness-Only/raw/main/Hundred%20Dharmas/100%20Dharmas.epub)

### Hai cách mở vault

1. **Dùng plugin Git để clone về máy**  
   Cài [Obsidian](https://obsidian.md/) và plugin cộng đồng **Obsidian Git**. Tạo [Personal Access Token](https://github.com/settings/tokens) trên GitHub, điền tên người dùng và khóa vào plugin, rồi kéo hoặc dán địa chỉ clone:

   `https://github.com/tiger-gong/Consciousness-Only.git`

   Xong thì chọn “Open folder as vault”.

2. **Tải nguyên thư mục, rồi thêm kho local**  
   Trên GitHub bấm **Code → Download ZIP**, giải nén, trong Obsidian chọn “Open folder as vault” trỏ vào thư mục đó. Phù hợp nếu chưa muốn cấu hình Git.

Xin đọc, sửa, bổ dịch. Làm trên nhánh hoặc fork của mình, rồi mở Pull Request.
