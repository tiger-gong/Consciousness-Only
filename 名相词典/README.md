# 名相词典 · 使用说明

> 结构：**每个名相 × 四种语言 = 4 篇笔记**，彼此用双链互连。
> 任意语言进入，都能悬停预览 / 点击跳转到其它语言。

## 目录结构

```
名相词典/
├── 中文/        ← 中文词形为文件名，正文为中文释义
├── English/     ← 英语词形为文件名，正文为英语释义
├── Français/    ← 法语词形为文件名，正文为法语释义
└── TiếngViệt/   ← 越南语词形为文件名，正文为越南语释义
```

## 如何使用

1. **搜索任意语言词形**：`Cmd/Ctrl + O` 输入「阿赖耶识」「ālaya」「storehouse」「conscience-réceptacle」「A-lại-da」都能找到。
2. **悬停预览**：在笔记底部「其它语言 / Other languages」处悬停 `[[链接]]`，弹出该语言卡片。
3. **图谱视图**：打开 Graph view，每个概念会显示为 4 个节点聚成一簇。
4. **标签筛选**：所有笔记带有标签 `#名相`。
