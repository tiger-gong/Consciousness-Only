# that which imagines (the imagining mind)

## Explanation（English）
Counterpart to that which is imagined. In the Thirty Verses on Consciousness-Only, “by this and that imagining” refers to the consciousness that imagines. Asaṅga held that the sixth, mental consciousness, is that which imagines; Sthiramati held that all eight consciousnesses can imagine; Dharmapāla and Nanda held that only the sixth and seventh are that which imagines—generally taken as the orthodox view.
