# object-as-condition
**梵 / Sanskrit**：*ālambana-pratyaya*

## Explanation（English）
The object taken as a condition, able to draw forth the cognizing mind. Divided into intimate object-as-condition (the image-aspect) and remote object-as-condition (the essential object).
