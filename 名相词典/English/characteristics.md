# characteristics
**梵 / Sanskrit**：*lakṣaṇa*

## Explanation（English）
Sanskrit lakṣaṇa, referring to the outward-appearing form or feature of a thing by which it can be distinguished and cognized; set in contrast to the inner “nature (essence).”
