# first six consciousnesses

## Explanation（English）
Refers to the six consciousnesses of eye, ear, nose, tongue, body, and mind—the cognitive functions that directly discern external objects (form, sound, smell, taste, touch, and dharmas); set in contrast to the seventh and eighth consciousnesses.
