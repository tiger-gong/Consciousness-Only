# căn bản phiền não
**梵 / Sanskrit**：*mūla-kleśa*

## Giải thích（Tiếng Việt）
Tham, sân, si, mạn, nghi, ác kiến sáu thứ, là căn bản của hết thảy phiền não; tùy phiền não nương đó mà sinh.
