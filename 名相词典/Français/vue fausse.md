# vue fausse
**梵 / Sanskrit**：*dṛṣṭi*

## Explication（Français）
Une des grandes afflictions concomitantes parmi les facteurs mentaux. Vue fausse, aussi dite vue incorrecte ou vue perverse. Le Cheng Weishi Lun dit : « Qu'est-ce que la vue fausse ? Envers les vérités et principes, investigation renversée ayant pour nature une discernement souillé ; elle fait obstacle à la vue juste et a pour activité d'attirer la souffrance. » Elle est établie provisoirement sur le facteur de discernement (prajñā), d'où « discernement souillé pour nature ». Elle s'ouvre en cinq : vue du soi (satkāya-dṛṣṭi), vues extrêmes, vue fausse/nihiliste, attachement aux vues, attachement aux préceptes et rites. Voir Cheng Weishi Lun, fasc. 6.
