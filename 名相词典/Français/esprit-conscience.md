# esprit-conscience
**梵 / Sanskrit**：*citta-vijñāna*

## Explication（Français）
Sanskrit citta-vijñāna, désignant largement le sujet mental qui discerne, délibère et accumule—c'est-à-dire un terme général pour les huit consciences ; c'est le cœur des études du Rien-que-conscience.
