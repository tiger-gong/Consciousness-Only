# transformateur discernant les objets

## Explication（Français）
L'un des trois transformateurs, aussi le troisième, pleinement « transformateur discernant les objets »—les six premières consciences (œil, oreille, nez, langue, corps, mental). Ces six discernent clairement les objets grossiers et évidents—les six objets de forme, son, odeur, saveur, toucher et dharmas—d'où le nom. Les Trente Stances disent : « Ensuite, le troisième transformateur, différencié en six sortes »—« conscience discernant les objets » étant le nom général, divisé en les six consciences connaissant les six objets.
