# condition prédominante
**梵 / Sanskrit**：*adhipati-pratyaya*

## Explication（Français）
Tout ce qui a une force efficace supérieure, pouvant aider l'apparition d'un autre dharma ou lui faire obstacle, est une condition dominante. Son champ est le plus vaste.
