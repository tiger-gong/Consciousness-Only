# 图谱：按语种看，不要四语搅在一起

讲记每个文件里同时挂了中英法越四条链，词条末尾又互相「其他语言」对链，所以**全局图谱**会变成一团四色毛线。这不是坏了，是四语同页造成的。要看清，用图谱左上角的**搜索框**做过滤：只留下一种语言的词条（需要时再加上讲记）。

打开方式：左侧功能区点「图谱」，或 `⌘G`（若已设快捷键）→ 打开「图谱视图」。

## 先试这一条（中文词条 + 讲记）

把下面整行贴进图谱搜索框，回车：

```
-path:名相词典/English -path:名相词典/Français -path:名相词典/TiếngViệt
```

英文、法文、越南文词条会隐去。剩下：中文词条、二十二讲、导读。点和线都只反映**中文名相**和讲记的关系。

本库已把这条设成图谱的默认搜索。若你改过搜索框，再贴一次即可。

## 四种「子图」过滤（复制即用）

**只要该语种的词条（没有讲记）**——点比较散，因为词条之间很少互链：

```
path:名相词典/中文
```

```
path:名相词典/English
```

```
path:名相词典/Français
```

```
path:名相词典/TiếngViệt
```

**该语种词条 + 讲记**——更能看出「哪一讲在用哪些词」：

```
-path:名相词典/English -path:名相词典/Français -path:名相词典/TiếngViệt
```

```
-path:名相词典/中文 -path:名相词典/Français -path:名相词典/TiếngViệt
```

```
-path:名相词典/中文 -path:名相词典/English -path:名相词典/TiếngViệt
```

```
-path:名相词典/中文 -path:名相词典/English -path:名相词典/Français
```

清空搜索框 = 回到四语全图。

## 颜色

图谱设置里已按文件夹上色：中文 / English / Français / TiếngViệt 各一种颜色。过滤之后只看一种颜色，会轻松很多。

## 局部图谱（从一个词出发）

打开某一个中文词条 → 右键「打开局部关系图谱」。深度设 1 或 2。这样只看「这个词和谁相连」，不必面对全书。

## 为什么不能做成四个永远分开的库

讲记是四语写在**同一页**里的。Obsidian 的图谱以文件为节点，一讲就是一个点，会同时连出四种语言。除非把每一讲拆成四个文件，全局图无法从根上拆开。过滤是不拆书的办法。
