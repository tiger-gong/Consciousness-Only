# 波斯匿王
**梵 / Sanskrit**：*Prasenajit*

## 释义（中文）
梵名 Prasenajit，中印度憍萨罗国王，与佛陀同时，皈依三宝，为佛教重要护法。《楞严经》等多有其问法记载。
