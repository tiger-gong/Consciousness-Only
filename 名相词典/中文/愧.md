# 愧
**梵 / Sanskrit**：*apatrāpya*

## 释义（中文）
此为心所有法中的善心所之一。愧者廉耻之心，做了坏事无颜见人曰愧。《成唯识论》曰：‘云何为愧，依世间力，轻拒暴恶为性，对治无愧，止息恶行为业。’愧和惭一样，可以止息恶行。见《成唯识论》卷六。
