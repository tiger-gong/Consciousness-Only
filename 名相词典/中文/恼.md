# 恼
**梵 / Sanskrit**：*pradāśa*

## 释义（中文）
此为心所有法中的小随烦恼心所之一．恼者恼怒，于忿恨之后，遇违逆事，因而爆怒，凶狠暴戾，有如蝎子螫人。此在《成唯识论》曰：‘云何为恼，忿恨为先，追触暴热，狠戾为性，能障不恼，蛆螫为业，谓追往恶，触现违缘，心便狠戾，多发嚣暴，凶鄙粗言，蛆螫他故。’见《成唯识论》卷六。
