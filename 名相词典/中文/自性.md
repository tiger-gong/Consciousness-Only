# 自性
**梵 / Sanskrit**：*svabhāva*

## 释义（中文）
指自体之本性，唯识家多称为自相。即诸法各自具有真实不变、清纯无杂的个性，即称为自性。换句话说，自性就是一切法的本质，也就是一切法本来如此，永远如此，不能以任何方法使之改变者，称为自性。事实上，一切法皆无自性，无自性始有可塑性，始有生灭变异。中观学派认为诸法皆由因缘和合所成，而无有一定的自性，故自性即空。所以中观学派‘缘起性空’的理论，即建立在一切法无自性的基础上。
