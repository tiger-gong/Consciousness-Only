# 烦恼
**梵 / Sanskrit**：*kleśa*

## 释义（中文）
梵语 kleśa，指扰乱身心、令众生流转生死的一切迷惑妄想，根本者为贪、瞋、痴等，唯识立六根本烦恼与二十随烦恼。
